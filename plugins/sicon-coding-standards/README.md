# Sicon Coding Standards

Sicon C# coding standards for readable, maintainable changes.

Install from the Sicon Team Marketplace, then enable the plugin.

## Included

- **Skill:** `csharp-coding-standards` — apply Sicon C# naming, practices, and Sage conventions
- **Rule:** auto-attaches on `**/*.cs` and points the agent at that skill
- **Reference:** `content/csharp-coding-standards.md` (Version 1.4, agent-oriented)

## Usage

On C# work, use or invoke the **csharp-coding-standards** skill. No slash command required.
